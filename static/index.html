Connection checklist

  • Set the correct WAZUH_API_URL in your local .env file.
  • Use an authorized Wazuh API account and verify network access to the configured port.
  • For live alert ingestion, configure an accessible WAZUH_ALERTS_FILE path or implement an approved Indexer integration.
  • Use trusted TLS certificates in any real deployment.
